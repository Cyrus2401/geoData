# GeoData

GeoData is a modern, intuitive, and fast web application that provides detailed real-time information about any country or city in the world.

## Features

- **Country Search**: Capital city, currency, languages, flag, coat of arms, national anthem (interactive audio), and map link.
- **City Search**: Precise geolocation, real-time weather, dynamically calculated local time, population, altitude, and Wikipedia description.
- **Design**: Clean interface, smooth staggered animations, responsive mobile-friendly layout, and a warm overall theme.

## Technologies Used

This project is lightweight and performance-oriented, built using standard web technologies combined with a set of public APIs.
