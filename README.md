# GeoData

GeoData est une application web statique permettant d'explorer des données détaillées sur les pays et les villes du monde.

## Description

GeoData aide les utilisateurs à obtenir rapidement des informations géographiques et socio-économiques sans configuration serveur. Elle est conçue pour les personnes curieuses du monde : voyageurs, étudiants, enseignants ou développeurs cherchant un prototype léger d'interface géographique.

## Fonctionnalités

- Recherche de pays par nom
- Affichage des données de pays : drapeau, codes ISO, capitales, population, superficie, langues, monnaie, fuseaux horaires, frontières, statut ONU, etc.
- Enrichissement des pays : type de régime, chef d'État, chef du gouvernement, religion officielle, date d'indépendance et hymne national audio
- Recherche de ville par nom
- Affichage des données de ville : coordonnées GPS, pays, région / État, météo en temps réel, humidité, vent, heure locale et lien OpenStreetMap
- Description de ville depuis la page Wikipedia
- Interface responsive et navigation simple entre recherche pays / recherche ville

## Utilisation

Aucune installation n'est nécessaire.

1. Clonez ou téléchargez le dépôt.
2. Ouvrez le fichier `index.html` avec un navigateur web.

> Les données sont récupérées depuis des APIs publiques, une connexion internet est donc requise.
