# 🌍 GeoData

GeoData est une application web moderne, intuitive et rapide qui permet d'obtenir des informations détaillées en temps réel sur n'importe quel pays ou ville du monde.

## ✨ Fonctionnalités

- **Recherche de Pays** : Capitale, monnaie, langues, drapeau, armoiries, hymne national (audio interactif) et lien vers la carte.
- **Recherche de Villes** : Géolocalisation précise, météo en temps réel, heure locale calculée dynamiquement, population, altitude, et description Wikipedia.
- **Design** : Interface épurée, animations fluides d'apparition en cascade, design réactif (mobile-friendly), et thème global chaleureux.

## 🛠️ Technologies utilisées

Ce projet est conçu de manière légère et performante en s'appuyant sur des standards web classiques couplés à un orchestre d'APIs publiques.

- **Langages** : HTML5, CSS3, JavaScript (ES6+), jQuery.
- **APIs de Données** :
  - **[Open-Meteo API](https://open-meteo.com/)** : Pour le géocodage des villes et la météo en temps réel (sans clé API).
  - **[REST Countries](https://restcountries.com/)** : Pour toutes les données liées aux pays.
  - **[Wikipedia REST API](https://fr.wikipedia.org/api/rest_v1/)** : Pour la récupération des résumés historiques et photos des villes.
  - **[Wikidata (SPARQL)](https://query.wikidata.org/)** : Pour requêter asynchronement la population et l'altitude des villes.

## 🚀 Utilisation

Aucun serveur ni installation n'est nécessaire ! 
1. Téléchargez ou clonez ce projet.
2. Ouvrez directement le fichier `index.html` dans n'importe quel navigateur récent (Chrome, Firefox, Safari).
